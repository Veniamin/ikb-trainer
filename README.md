# Тренажёр ИКБ

Тренажёр для подготовки к Межрегиональной олимпиаде школьников имени И. Я. Верченко по профилю
«Информатика и компьютерная безопасность» (поток 8–10 классов). Ответы проверяются автоматически.

**Открыть тренажёр:** https://veniamin.github.io/ikb-trainer/

Это неофициальный проект, он не связан с организаторами олимпиады. Условия задач взяты из открытых материалов
на сайте олимпиады [ikb.mtuci.ru](https://ikb.mtuci.ru/materials/); права на них принадлежат организаторам.

## Как заниматься

1. Нажимайте **«▶ Продолжить»** на главной странице. Тренажёр сам выбирает следующий шаг: теорию, тренировку,
   задачу олимпиады или пробный тур.
2. Каждая тема проходит в три шага:
   - **Теория:** короткий конспект с примерами на Python.
   - **Тренировка:** задачи в стиле олимпиады, при каждом запуске с новыми числами.
   - **Задачи олимпиады:** настоящие задания прошлых лет.
3. Если не получается, берите подсказки по одной. Если открыть решение, задача не засчитывается, и тренажёр
   попросит решить второй вариант той же задачи самостоятельно.
4. Кнопка «Спросить Claude» готовит вопрос для [claude.ai](https://claude.ai). Claude отвечает как наставник:
   задаёт наводящие вопросы и не называет ответ.
5. Пробные туры повторяют отборочный этап: 5 задач за 4 часа, без подсказок.
6. **Видеоурок «Шифры с нуля»** (тема «Классические шифры»): 10 глав с голосом и анимацией — номера букв и
   остаток от деления, Цезарь, частотный анализ, Виженер, перестановки, решётка Кардано, XOR. После каждой главы —
   упражнения с проверкой. Пробел — пауза, стрелки — предыдущая/следующая фраза.

Держите под рукой Python: многие задачи быстрее решить коротким скриптом, чем считать вручную.

Прогресс хранится в браузере. Занимайтесь на одном устройстве и в одном браузере, не открывайте тренажёр в режиме
инкогнито. Чтобы перенести прогресс на другое устройство, скачайте резервную копию в разделе «Отчёт» и загрузите
её там же на новом устройстве.

## Что внутри

- **211 задач** за 2006–2026 годы, у 181 есть автопроверка.
  - Основной план — задачи отборочного и заключительного этапов для 8–10 классов за 2020–2026 годы.
  - Дополнительно — вторые варианты, задачи старых лет и задачи 11 класса для повышенного уровня.
- **25 генераторов тренировочных задач** по 8 темам:
  - системы счисления и ASCII;
  - хеши и контрольные суммы;
  - чтение кода и обфускация;
  - классические шифры;
  - перебор;
  - нагрузка и логи;
  - стеганография;
  - сети и доступ.
- **4 пробных тура:** отборочные этапы 2024-25 и 2025-26 для 8–10 классов и тур 11 класса.
- **Отчёт для родителя:** время занятий по дням, прогресс по темам и результаты пробных туров.
- **Тетрадь ошибок:** задачи с неверными ответами или открытым решением.

Ответы перепроверены программно. В официальных материалах нашлось несколько ошибок в ответах и условиях;
в тренажёре они исправлены, а в решении таких задач объяснено, в чём расхождение.

## Как это устроено

Статическая страница без сборки и зависимостей. Её можно открыть и локально: скачайте репозиторий и откройте
`index.html` в браузере, интернет не нужен.

| Файл | Что в нём |
|---|---|
| `index.html`, `style.css` | оболочка страницы |
| `app.js` | план занятий, задачи, проверка ответов, пробные туры, отчёт |
| `theory.js` | конспекты по темам |
| `generators.js` | генераторы тренировочных задач |
| `lesson.js`, `lesson-ciphers.js` | плеер видеоуроков и урок «Шифры с нуля» (сцена, фразы диктора, упражнения) |
| `audio/` | озвучка уроков (генерируется, вручную не редактируется) |
| `bank.js` | банк задач олимпиады (генерируется, вручную не редактируется) |
| `img/`, `files/` | картинки и файлы к задачам |
